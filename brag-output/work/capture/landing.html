Built for the inbox, not the browser

Email clients are hostile places. MailMotion works within their rules instead of hoping for the best.

It renders for real

Table layouts, inline styles, hosted GIFs and PNG icons. No SVG, no <style>, no data URIs that Gmail strips.

Private by default

No tracking pixels, no read receipts, no accounts. Photos are processed in your browser and metadata is stripped.

Open source

Self-host it with Docker, use the CLI in CI, or fork a design. The engine is MIT, the apps are AGPL.

Security built in

Everything is HTML-escaped, links are https-only, uploads are re-validated and the builder ships a strict CSP.

From idea to installed in a few minutes

Design

Pick a design, enter your name and photo, and tweak colours, fonts, socials and your signature mark.

Host the images

Gmail needs public image URLs. Publish free to your own GitHub Pages in one click, or use your own storage.

Install

Copy the signature into Gmail or Outlook, or use the Apple Mail file and the send-to-phone page.
