Step-by-step guides

Gmail
Gmail on the web
  1. Click "Copy formatted signature" below.
  2. In Gmail open Settings (the gear) → See all settings → General.
  3. Scroll to Signature, choose "Create new" (or edit one) and paste with Ctrl/Cmd+V.
  4. Under "Signature defaults" pick it for new emails and replies, then Save Changes.

Gmail limits a signature to 10,000 characters. The builder blocks the copy if yours is over.

Gmail app (iOS / Android)
  1. The Gmail app can only set a plain-text mobile signature. Instead, turn the mobile signature OFF so the app uses the web signature for Google accounts.
  2. In the Gmail app: Menu → Settings → your account → Mobile Signature → turn it off.
  3. Set the signature on Gmail web (above); it will be used when you send from the app.

No paste needed on the phone. If your account is not a Google account, use the send-to-phone page instead.

Outlook
Outlook on the web and new Outlook
  1. Click "Copy formatted signature" below.
  2. Open Settings → Accounts → Signatures (new Outlook) or Settings → Mail → Compose and reply (outlook.com).
  3. Choose "New signature", paste with Ctrl/Cmd+V, and choose your defaults.
  4. Save.
Classic Outlook for Windows
  1. Download the .htm file below.
  2. Press Win+R, type %APPDATA%\Microsoft\Signatures and press Enter.
  3. Copy the downloaded .htm into that folder, then restart Outlook.
  4. File → Options → Mail → Signatures and pick it. (Or paste the copied signature there.)

Outlook 2016 and 2019 show only the first frame of each GIF, which is why frame 1 is always complete. Microsoft 365 builds animate.

Outlook for Mac
  1. Click "Copy formatted signature" below.
  2. Outlook → Settings → Signatures → +.
  3. Paste into the editor, name it, and choose your defaults.
Outlook app (iOS / Android)
  1. Open the send-to-phone page on your phone (QR code or link below).
  2. Tap "Copy signature".
  3. In Outlook: Settings → your account → Signature, and paste.

Formatting support in the mobile Outlook signature box varies by version. Recent Microsoft 365 builds can sync signatures from the web instead.

Apple Mail
Mail on macOS
  1. Mail → Settings → Signatures → + to create a placeholder signature, and note its name.
  2. Quit Mail completely.
  3. Download the .mailsignature file below and replace the placeholder file in ~/Library/Mail/V10/MailData/Signatures/ (the placeholder is the newest file there; V-number varies).
  4. Right-click the new file → Get Info → tick "Locked" so Mail does not reformat it, then reopen Mail.

Pasting also works for simple designs. The file route keeps everything intact.

Mail on iPhone / iPad
  1. Open the send-to-phone page on your phone (QR code or link below) and tap "Copy signature".
  2. Settings → Apps → Mail → Signature (older iOS: Settings → Mail → Signature), and paste.
  3. If the formatting looks lost, shake the phone and choose "Undo Change Attributes" to restore it.
iCloud Mail on the web
  1. The iCloud signature editor has limited formatting. We recommend sending from the Mail apps above.
  2. If you still want to try: iCloud Mail → Settings → Composing → Signature, and paste.

Install steps change as mail apps update. If something differs, see the install guides and the compatibility page.
